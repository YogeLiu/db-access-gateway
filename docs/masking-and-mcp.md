# MCP 客户端与字段脱敏

Access Token 页面下方常驻 Claude Code / Codex 两份 MCP 配置，各有复制按钮。
配置始终只引用 DB_ACCESS_TOKEN 环境变量，不读取或嵌入真实 Token。
Token 列表通过眼睛图标切换明文 / 脱敏；开关仅影响列表。
页面创建 Token 不再选择有效期，新建默认永久有效；不修改旧 Token 的有效期。
删除会永久移除本人指定 Token 的数据库记录，删除后失效且不再展示，不自动清理其他 Token。
新 Token 使用 AES-GCM 加密保存，密钥由服务端 Token pepper 分离派生；认证仍使用摘要。
仅登录的所属用户能获取有效 Token 原文，返回禁止缓存，不在列表接口暴露原文。
密文绑定 Token 和用户 ID；必须妥善保管服务端 pepper，变更它会影响解密与认证。
升级前只有摘要的旧 Token 无法恢复原文，需要新建 Token 使用此功能；不自动撤销旧 Token。
复制按钮复制变量配置，客户端启动前需设置 DB_ACCESS_TOKEN 为完整 Token（不含 Bearer 前缀）。
Claude Code 使用 Authorization: Bearer ${DB_ACCESS_TOKEN}；Codex 使用 bearer_token_env_var = "DB_ACCESS_TOKEN"。
在同一终端设置变量后启动客户端，或由环境管理工具注入；GUI 启动的客户端也需要继承此变量。
网关地址默认使用浏览器当前来源，请按客户端实际可访问地址调整。
不要把含真实 Token 的环境文件或命令提交到代码仓库。

- Codex：合并到 ~/.codex/config.toml。
- Claude Code：合并到项目 .mcp.json。

配置格式参考：
https://developers.openai.com/codex/mcp/
https://code.claude.com/docs/en/mcp

管理员在“字段脱敏”依次选择数据库资源、数据表，之后才请求并展示该表字段。
支持搜索表名、搜索字段和字段分页。字段显示方式如下：

| 模式 | 返回值 |
| --- | --- |
| 明文 | 原始值，未配置字段的默认方式 |
| 半脱敏 | 自定义保留前后 Unicode 字符数（各 0–64），中间固定四个星号；长度不超过保留位数总和时全隐藏 |
| 全脱敏 | 固定六个星号 |

NULL 始终保持 NULL；脱敏的非空数字等值返回字符串。
新增半脱敏规则默认手机号格式：前 3 后 4，例如 13812345678 → 138****5678。
还提供姓名（前 1 后 1）、证件号（前 6 后 4）快捷格式与样例预览。
历史规则升级后仍保留前 1 后 1，不自动改变已有策略。
规则作用于该逻辑资源所有 MCP 用户，不修改目标数据库数据。
同一物理数据库登记为不同资源时，各资源需分别配置。

实现将基础表替换为脱敏的派生表，外层 SELECT、别名、JOIN、星号、
子查询、UNION 和允许的内置函数都只读取处理后的值。
因此 WHERE、JOIN 条件、排序和聚合也基于脱敏后的值，结果语义可能改变。
包含非明文规则的资源拒绝写入、视图和非白名单函数；
无法解析、未知表和无法加载规则/元数据时拒绝返回数据。
这是字段显示控制，不是差分隐私或防止所有统计推断的系统。

规则与资源版本在同一事务更新，旧版本的在途查询会在返回结果前被拒绝。
审计继续记录用户提交的原始 SQL，不记录查询结果；
SQL 文本中的用户输入字面量并不由字段脱敏规则清洗。

验证：go test ./...；MySQL 集成测试需设置 MASKING_TEST_DSN，
运行 go test ./internal/masking -run TestMySQLMasking -v。
测试仅建立会话级临时表并写入合成数据，不修改业务表。
